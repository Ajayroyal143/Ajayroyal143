### 🧾 Salary Slip Analyzer Bot
[🔗 Live Demo](https://salary-slip-analyzer-bot-mayh59vuntogvqmdsus2wa.streamlit.app/)  
[📂 GitHub Repo](https://github.com/Ajayroyal143/salary-slip-analyzer-bot)

An AI-powered Streamlit web app that extracts and analyzes salary data from Indian payslips (PDF/TXT) using regex and PDF parsing.  
- Supports multiple uploads with trend visualization  
- Built with Python, Streamlit, Pandas, pdfplumber  
- Used by jobseekers and FinTech enthusiasts for payroll analysis
